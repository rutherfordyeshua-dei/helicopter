# Rotor Command — resultados

## Escena y presentación

- [ ] El juego muestra un valle 3D estilizado con agua, terreno, árboles, helipuerto, cielo y waypoints visibles.
- [ ] El helicóptero tiene una silueta reconocible con rotor principal y rotor de cola animados.
- [ ] La presentación usa alto contraste, retícula de navegación y HUD aeronáutico legible.

## Vuelo y misión

- [ ] El jugador puede despegar y aterrizar en la base, controlar altitud y velocidad, cabeceo, alabeo, guiñada y colectivo.
- [ ] W/S, A/D, Q/E, Shift/Ctrl, Space, C, Esc y R ejecutan las funciones indicadas para teclado de Windows.
- [ ] La misión muestra tres puntos de control, registra su paso y se completa al regresar a la base con una aproximación estable.
- [ ] El HUD muestra altitud, velocidad, rumbo, combustible, RPM, waypoint y auto-hover.
- [ ] Hay pausa, reanudación, reinicio y cámara tercera persona/cabina.

## Entrega técnica

- [ ] El proyecto conserva el starter Three.js/Vite y ejecuta `pnpm build` sin errores.
- [ ] El smoke test inicializa la partida y no detecta errores de consola o red.
- [ ] Existe una compilación estática lista para envolver como aplicación Windows.
